This project focuses on applying machine learning techniques to educational data. The objective is to
predict whether a student will correctly answer a diagnostic question using their previous responses
and response patterns from other students. The dataset contains responses from 542 students to 1,774
diagnostic questions.

The project involves implementing and comparing multiple machine learning approaches, analyzing their
performance, and exploring modifications that may improve prediction accuracy.

Skills Covered:
Python programming
NumPy, SciPy, Pandas, and PyTorch
Data preprocessing and sparse matrices
K-Nearest Neighbours (KNN)
Collaborative filtering
Item Response Theory (IRT)
Gradient-based optimization
Matrix factorization / neural-network autoencoders
Hyperparameter tuning
Regularization
Bootstrap ensemble learning
Model validation and evaluation
Machine learning experimentation and performance analysis

The project emphasizes not only implementing models but also understanding their limitations, designing
experiments, comparing approaches, and communicating results scientifically.
